Metal Gear Solid (GOG PC version) running natively on macOS
===========================================================

Start: double-click "Metal Gear Solid.app" (or "Metal Gear Solid VR Missions.app") in this folder.
The apps must stay in the game folder (next to mgsi.exe / mgsvr.exe). The first launch asks you to
accept the game's licence (EULA.RTF).

The game's Windows program was translated into native Apple Silicon code; no Wine, no emulator.
The 3D scenes are drawn at your window's full resolution with 4x anti-aliasing, text is drawn
with macOS fonts at full resolution, and menu/HUD pixel art is smoothed.

Keyboard (the game's defaults; change them in the game's own options)
  Arrow keys        move
  Esc               Start (pause, skip cutscenes)
  Tab               Select
  Space             Circle (confirm in menus)
  Shift             Cross
  Ctrl              Square
  X                 Triangle
  Q / W             L1 / R1
  A / S             L2 / R2
  Cmd+F             full screen on/off (the game starts in full screen; each app remembers
                    your last choice for the next start)
  Cmd+Q             quit

A game controller (Xbox, PlayStation, ...) that is connected before you start the game is offered
to the game as a joystick; set it up in the game's controller options (not tested).

Saves go to the SavedGames folder here, settings to mgs.cfg and mgsvideo.cfg.
